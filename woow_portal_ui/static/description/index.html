Woow Portal UI

Clean, Modern Portal Experience for Odoo 18

Key Features

Portal Home Dashboard

Time-based greeting card with user avatar, module search bar, notification preview, and smart module cards that hide when count is zero.

Unified Notification Center

4-tab navigation (All / Messages / Notifications / Activities) with dynamic badge counts, real-time search, filter, sort, and group capabilities.

Swipe-to-Action

Swipe right on notifications to mark as read (blue hint) or on activities to mark as done (green hint). Supports both touch and mouse drag.

Detail Modal

Click any notification or activity card to view full details in a modal. Mark read, complete activities, or navigate to source documents.

Role-Based UI Isolation

Portal users see 3 tabs (no activities). Internal users see 4 tabs. Server-side data isolation ensures each user only sees their own notifications.

87 Automated Tests

Comprehensive Playwright test suite covering all features, interactions, edge cases, and security scenarios with 100% pass rate.
